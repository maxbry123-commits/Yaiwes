# PocketIDE v1.0.1

PocketIDE v1.0.1 is the current Arm64 Android demonstration release for the Arm AI Optimization Challenge.

## What changed

- Releases an idle native GGUF or PTE model when PocketIDE moves to the background, reducing background memory pressure without clearing projects, terminal state, chat history, saved calibration, or benchmark reports.
- Keeps an active generation or benchmark running safely and defers model release until the work finishes. Returning to PocketIDE cancels a pending release.
- Keeps the native llama.cpp prompt and decode microbenchmark in Quick mode, while Deep and Sustained focus on end-to-end generation, energy, thermal behavior, and stability.
- Fixes the exported benchmark resource plan so it reports the selected chat profile and requested output budget instead of the smaller native microbenchmark request.
- Updates benchmark report and JSON output to schema 13.

## Download

Download `PocketIDE-arm64.apk` for an `arm64-v8a` phone running Android 8.0 or newer. Models are not bundled. Import a compatible GGUF model after installation or use a model download option in Settings.

This is a debug-signed demonstration APK, not a Play Store production build.

- APK size: 92,264,570 bytes
- SHA-256: `2eecd807d6c184bd2f1b3155b2cfec0bbf7059e7e8591607ee6e8faad8b28ab0`

## Verification

- Debug APK assembly passed.
- Android lint passed.
- 214 JVM, Robolectric, and vendored-runtime tests passed with no failures or skips.
- The APK signature verifies and the packaged native ABI is `arm64-v8a` only.
- Android 16 KiB page-alignment verification passed.

Physical inference speed is device dependent. This release preserves the previously measured two-thread Armv8.2 dot-product profile and does not claim a new tokens-per-second result without a new physical-device measurement.
